AI 語言模型在做什麼What a language model does

ChatGPT、Claude、Gemini 這些 AI，背後都是「大型語言模型」。聽起來很玄，但它做的事情可以用一句話說完。這一章用一個你可以親手操作的迷你模型，帶你看懂它。

ChatGPT, Claude and Gemini are all built on "large language models". It sounds mysterious, but what they do fits in one sentence. This chapter uses a tiny model you can play with to show you how.

一句話說完In one sentence

一句話重點Key point

語言模型是一個「很會接話」的程式：看前面的文字，猜下一個字最可能是什麼，接上去，再猜下一個。

A language model is a program that is very good at continuing text: it looks at the words so far, guesses the most likely next one, adds it, and guesses again.

你的手機輸入法就有類似的功能：打了「今天」，它會建議「天氣」「晚上」「要不要」。大型語言模型做的是同一件事，只是它讀過的文字多到難以想像，所以猜得非常準，準到看起來像在「思考」和「對話」。

Your phone keyboard does something similar: type "see you" and it suggests "tomorrow", "soon", "later". A large language model does the same thing, except it has read an unimaginable amount of text, so its guesses are good enough to look like thinking and conversation.

    為什麼 AI 會一本正經地說錯話Why AI says wrong things so confidently

    第二點很重要。語言模型學到的是「什麼樣的文字聽起來通順、合理」，而不是「什麼是真的」。大多數時候兩者一致，所以它看起來很博學；但當它不知道答案時，它不會自動說「我不知道」，而是照樣接出一段聽起來很對的話。這種現象叫做「幻覺」（hallucination）。

    That second point matters. A language model learns what text sounds fluent and plausible, not what is true. Most of the time those coincide, so it seems knowledgeable; but when it doesn't know, it doesn't automatically say "I don't know". It continues with something that sounds right. This is called hallucination.

    兩個一定會遇到的詞：token 與 context windowTwo words you'll meet everywhere: tokens and the context window

    Token

    我們的迷你模型一次猜「一個字」。真正的模型一次猜的是一個 token：可能是一個字、半個英文單字，或一個標點。你可以把 token 想成模型讀寫文字的「最小單位」。它重要的原因很實際：AI 服務是依照 token 數量收費的，長度限制也是用 token 計算。一段文字大約是多少 token，依模型與語言而不同。

    Our mini model guesses one character at a time. A real model guesses one token at a time: a word, part of a word, or a punctuation mark. Think of tokens as the model's smallest unit of reading and writing. They matter for a practical reason: AI services charge by the token, and length limits are counted in tokens too. How many tokens a piece of text takes depends on the model and the language.

    Context window

    模型每次回答時，能「看到」的文字有上限，這個上限叫 context window（上下文視窗）。可以把它想成模型的「工作記憶」：你的問題、之前的對話、你貼給它的文件，全部加起來都要放得進去。現在的模型可以一次看非常多文字，但放得越多，每次的費用越高、速度也越慢。

    Each time a model answers, there's a limit on how much text it can "see": the context window. Think of it as working memory: your question, the earlier conversation and any documents you pasted all have to fit. Modern models can take in a great deal of text, but the more you include, the more each request costs and the slower it gets.

    小測驗Quiz

    1. 語言模型產生回答的方式，最接近下面哪一個？1. Which is closest to how a language model produces an answer?
    模型本身不會去查資料庫或上網，它是根據學到的規律，一個 token 一個 token 地產生文字。
    The model itself doesn't query a database or browse the web; it generates text token by token from the patterns it learned.
    2. AI 很有自信地回答了一個你們公司內部的規定。你應該？2. The AI confidently answers a question about your company's internal policy. You should:
    內部規定不在它的訓練資料裡。講得具體不代表正確，兩次答案一樣也可能兩次都是編的。
    Internal policies aren't in its training data. Specific doesn't mean correct, and two matching answers can both be invented.
    3. 為什麼工程師要在意 token 數量？3. Why do engineers care about token counts?
    送出與收到的 token 都會計費，而且每次能放進 context window 的量有上限。
    Tokens sent and received are both billed, and there's a cap on how many fit in the context window.
