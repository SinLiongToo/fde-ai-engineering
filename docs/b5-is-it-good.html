它做得好嗎？簡單的測試Is it any good? Simple tests

準備一份考卷Prepare an exam

一句話重點Key point

寫下一組問題和正確答案，每次修改 prompt 或程式後都重考一次。分數變差，就不要上線。

Write down a set of questions with correct answers, and re-run them after every prompt or code change. If the score drops, don't ship.

為什麼要每次都重考？因為 AI 系統的改動常常「修好一個、弄壞另一個」：你為了讓它回答特休問題而改了 prompt，結果病假問題的答案變了。只試你剛改的那一題，是看不出來的。

Why re-run every time? Because changes to AI systems often fix one thing and break another: you tweak the prompt to fix annual-leave answers, and sick-leave answers change. Testing only the question you just fixed won't reveal that.

好的考卷包含三種題目：

A good exam includes three kinds of question:

  • 一般題：使用者最常問的問題。最好從真實的提問紀錄裡挑。
  • 陷阱題：文件裡沒有答案的問題。正確答案是「不知道」。
  • 曾經出錯的題目：每次發現錯誤，修好後就把它加進考卷，確保以後不會再犯。
  • Common questions: what users ask most, ideally taken from real logs.
  • Trick questions: questions the documents don't answer. The right answer is "I don't know".
  • Past mistakes: every time you find and fix an error, add it to the exam so it can't silently come back.

動手試：你來當閱卷老師Try it: you're the grader

這五個回答，哪些可以通過？Which of these five answers pass?

根據 B4 的員工手冊，判斷 AI 的每個回答是否通過。規則：內容要正確、要標註出處、手冊沒寫的要說不知道。判斷完按「對答案」，順便看看「只檢查關鍵字」的自動評分表現如何。

Using the handbook from B4, decide whether each AI answer passes. Rules: correct content, a citation, and "don't know" when the handbook doesn't say. Then press "Check" and see how a keyword-only auto check compares. (Answers are in Chinese; the explanations are translated.)

自動評分：有用，但有極限Automatic grading: useful, but limited

人工閱卷很準，但很慢。所以我們會用程式自動檢查能檢查的部分，例如：答案裡有沒有出現關鍵數字、有沒有標註出處、陷阱題有沒有說「不知道」。剛才的示範也告訴你它的極限：「病假超過三天不需要附任何證明」包含了關鍵字「三天」，但意思完全相反。

Human grading is accurate but slow, so we let code check what it can: whether the key number appears, whether there's a citation, whether trick questions get "I don't know". The demo also showed the limit: "sick leave over three days needs no certificate" contains the keyword "three days" but means the opposite.

實務上兩者搭配使用：程式檢查每一題、每一次；人定期抽查一部分，特別是重要的題目。進階篇第 7 章會教更完整的做法。

In practice you combine both: code checks every question every time, and people regularly spot-check a sample, especially the important ones. Core chapter 07 covers the fuller approach.

程式碼：一份會自動考試的考卷The code: an exam that grades itself

兩題沒通過，正好是 B4 介紹的兩種搜尋失敗。這就是考卷的價值：問題被清楚地記錄下來，等你改進搜尋方法之後，重考一次就知道有沒有修好、有沒有弄壞其他題。

The two failures are exactly the two search failures from B4. That's the value of an exam: problems are recorded clearly, and once you improve the search you re-run it to see whether you fixed them without breaking anything else.
