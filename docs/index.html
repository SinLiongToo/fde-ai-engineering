AI 工程實戰：把 LLM 系統做到能上線 AI engineering: getting LLM systems to production

這門課分三部分。入門篇用白話和互動示範，搞懂 AI 應用怎麼運作。中級篇從頭做一個真的能用的員工手冊機器人，每章加一個功能。進階篇是前線部署工程師（FDE）把系統放進客戶正式環境時用的方法。每一章都附可以在本機執行的 Python 程式。

The course has three parts. Basics explains how AI applications work, in plain language with interactive demos. Intermediate builds a working employee-handbook bot from scratch, one feature per chapter. The core course covers the methods Forward Deployed Engineers (FDEs) use to put systems into customers' production environments. Every chapter comes with Python code you can run locally.

You know HTTP APIs, SQL, Git, testing and deployment, and want to turn AI demos into systems customers sign off on and ops teams can run.

這門課不教 Python 語法、機器學習理論或模型訓練。它假設你用現成的模型 API，把力氣花在模型周圍的工程上。遇到看不懂的名詞，可以查詞彙表。

The course doesn't teach Python syntax, ML theory or model training. It assumes you call hosted model APIs and spend your effort on the engineering around them. Unfamiliar term? Check the glossary.

        怎麼使用這門課How to use this course

        • 每章開頭有學習目標，結尾有小測驗。測驗答錯會顯示說明，不計分。
        • 入門篇每一章、中級篇第 2 到 5 章，以及進階篇第 4 到 7 章，都有可以在瀏覽器裡操作的示範。示範用的是和 Python 練習相同的演算法，不是寫死的動畫。
        • 程式碼都在 labs/ 資料夾，完全離線可執行，不需要 API key。入門篇的程式在 labs/beginner/，中級篇在 labs/intermediate/。安裝方式見第 9 章。
        • 右上角可以切換中英文與深淺色。閱讀進度存在你的瀏覽器裡。
        • Each chapter opens with learning objectives and ends with a short quiz. Wrong answers show an explanation; nothing is scored.
        • Every basics chapter, intermediate chapters 2–5 and core chapters 4–7 include in-browser demos that run the same algorithms as the Python labs, not canned animations.
        • All code lives in labs/ and runs offline with no API key. Basics code is in labs/beginner/, intermediate in labs/intermediate/. Setup is in chapter 9.
        • Switch language and theme from the top right. Your reading progress is stored in your browser.
        關於數字About numbers

        這門課刻意不提供「準確率提升 X%」「延遲低於 Y 毫秒」這類通用數字。這些數字取決於你的資料、模型與流量，拿別人的數字當目標是常見的錯誤。課程教的是怎麼在你的系統上量出自己的數字（第 7 章）。

        This course deliberately avoids generic claims like "accuracy improves by X%" or "latency under Y ms". Those numbers depend on your data, model and traffic, and borrowing someone else's figures as targets is a common mistake. What the course teaches is how to measure your own numbers on your own system (chapter 7).
