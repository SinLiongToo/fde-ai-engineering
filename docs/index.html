AI 工程實戰：把 LLM 系統做到能上線 AI engineering: getting LLM systems to production

前線部署工程師（Forward Deployed Engineer，FDE）的工作，是進到客戶的環境裡，把模糊的需求變成真的在跑、有人在用、出事時查得出原因的系統。這門課整理這個角色最常用到的工程方法：結構化輸出、檢索、Agent、評測與上線。每一章都對應一段可以在本機執行的 Python 程式。

A Forward Deployed Engineer (FDE) goes into a customer's environment and turns a vague request into a system that runs, gets used, and can be debugged when it breaks. This course covers the engineering methods the role relies on most: structured output, retrieval, agents, evaluation and production operations. Every chapter maps to Python code you can run locally.

這門課適合誰Who this is for

你已經會寫正式環境的程式：懂 HTTP API、SQL、Git、測試與部署，也用過 LLM API 或 ChatGPT 之類的工具。你想知道的是：怎麼把一個 demo 做成客戶願意簽收、維運團隊接得住的系統。

這門課不會教 Python 語法、機器學習理論或模型訓練。它假設你用現成的模型 API，把力氣花在模型周圍的工程上。

You already ship production code: you know HTTP APIs, SQL, Git, testing and deployment, and you have used an LLM API or a chat assistant. What you want to learn is how to turn a demo into a system a customer will sign off on and an operations team can run.

This course does not teach Python syntax, ML theory or model training. It assumes you call hosted model APIs and spend your effort on the engineering around them.

    怎麼使用這門課How to use this course

    • 每章開頭有學習目標，結尾有小測驗。測驗答錯會顯示說明，不計分。
    • 第 4 到 7 章有可以在瀏覽器裡操作的示範。示範用的是和 Python 練習相同的演算法，不是寫死的動畫。
    • 程式碼都在 labs/ 資料夾，完全離線可執行，不需要 API key。安裝方式見第 9 章。
    • 右上角可以切換中英文與深淺色。閱讀進度存在你的瀏覽器裡。
    • Each chapter opens with learning objectives and ends with a short quiz. Wrong answers show an explanation; nothing is scored.
    • Chapters 4–7 include in-browser demos that run the same algorithms as the Python labs, not canned animations.
    • All code lives in labs/ and runs offline with no API key. Setup is in chapter 9.
    • Switch language and theme from the top right. Your reading progress is stored in your browser.
    關於數字About numbers

    這門課刻意不提供「準確率提升 X%」「延遲低於 Y 毫秒」這類通用數字。這些數字取決於你的資料、模型與流量，拿別人的數字當目標是常見的錯誤。課程教的是怎麼在你的系統上量出自己的數字（第 7 章）。

    This course deliberately avoids generic claims like "accuracy improves by X%" or "latency under Y ms". Those numbers depend on your data, model and traffic, and borrowing someone else's figures as targets is a common mistake. What the course teaches is how to measure your own numbers on your own system (chapter 7).

    自我評估：從哪裡開始讀Self-assessment: where to start

    For each question pick the option closest to what you actually do today. The result only suggests a reading order and stays in your browser.
